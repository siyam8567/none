# Ritu Birthday Website 🎂

A small animated birthday page with a letter that types itself out.

## Files
- `index.html` – the page
- `style.css` – all styling and animations
- `images/` – photos, balloons, hearts and other artwork

## View it online (GitHub Pages)
1. Go to **Settings → Pages**.
2. Under "Build and deployment", choose **Deploy from a branch**.
3. Select the **main** branch and the **/ (root)** folder, then click **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Run it locally
Just open `index.html` in a browser.
